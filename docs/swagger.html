TradingPagingList — API 文件

Product CRUD + 伺服器端分頁（預設 pageSize=10）· Spring Boot 3 · Java 21 · H2（dev）／PostgreSQL（prod）· Vue 3 + Vite 前端

CodeGraphic architecture.md testing.md Runtime Swagger UI（:8091）

啟動與位址

啟動.\gradlew.bat bootRun（前端另起 Vite :5174）
Port8091
OpenAPI JSONhttp://localhost:8091/v3/api-docs
Swagger UIhttp://localhost:8091/swagger-ui.html
H2 Consolehttp://localhost:8091/h2-console（JDBC jdbc:h2:mem:paginglist，帳號 sa，密碼空白）
驗證.\gradlew.bat check

API 分組（實際 Controller）

  • Products：GET /api/v1/products（分頁，預設每頁 10 筆）、GET /{id}、POST /api/v1/products、PUT /{id}、DELETE /{id}
  • 前端：Vue 3 分頁表格元件（Vite dev server http://localhost:5174）。

認證與範例流程

  • 無認證（無 Spring Security／JWT），啟動後可直接呼叫。
  • 範例：POST /api/v1/products 建立多筆 → GET /api/v1/products?page=0&size=10 觀察分頁中繼資料 → 換頁比較 page=1。

本頁載入 http://localhost:8091/v3/api-docs，請先啟動應用。若以 file:// 直接開啟本頁而無法載入， 請改用 http://localhost:8091/swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
